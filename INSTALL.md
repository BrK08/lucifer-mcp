## ⚡ Fastest Way — One-Command Setup (`start_mcp.py`)

If you want to connect to **ChatGPT Web, Claude Web, Gemini, or any HTTP MCP client**:

```powershell
git clone https://github.com/BrK08/lucifer-mcp.git
cd lucifer-mcp
pip install -r requirements.txt
python start_mcp.py
```

1. **Remote HTTPS Tunnel (Optional for Web AI like ChatGPT / Claude.ai):**
   If you don't have `cloudflared` yet, install it once on Windows:
   ```powershell
   winget install Cloudflare.cloudflared
   ```
   When you run `python start_mcp.py`, the terminal prints:
   - `Local MCP URL   : http://127.0.0.1:8828/mcp`
   - `Remote MCP URL  : https://xxxx.trycloudflare.com/mcp`
2. Paste `https://xxxx.trycloudflare.com/mcp` into **ChatGPT → Settings → Connectors → Add custom MCP server** (or **Claude → Settings → Connectors → Add custom connector**).
3. Run the 1-line bridge inside **Lucifer v2.88 p2 → Executor** (Step 5 below).

## Step 4 — Connect Your AI Client

### Option A — ChatGPT Web / Claude.ai Web & Mobile (HTTP + Cloudflare Tunnel)

Run in terminal (leave it running while playing):
```bat
python start_mcp.py
```
Copy the `https://xxxx.trycloudflare.com/mcp` URL printed in the terminal and add it as a Custom MCP Connector in ChatGPT or Claude.

---

### Option B — Claude Desktop (`stdio` mode, zero tunnel needed)

Open `%APPDATA%\Claude\claude_desktop_config.json` (Windows) or `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) and add:

```json
{
  "mcpServers": {
    "lucifer-mcp": {
      "command": "python",
      "args": ["C:\\lucifer-mcp\\server.py"]
    }
  }
}
```

Restart Claude Desktop. It automatically launches the local Relay on port `8829` in the background.

---

### Option C — Cursor / Antigravity / VS Code / Windsurf (`stdio` mode)

Add to your IDE MCP config (`mcp_config.json`, `.cursor/mcp.json`, or `.vscode/mcp.json`):

```json
{
  "mcpServers": {
    "lucifer-mcp": {
      "command": "python",
      "args": ["C:\\lucifer-mcp\\start_mcp.py", "--stdio"]
    }
  }
}
```

*(Need multiple AI clients sharing one Lucifer session at the same time? Start `python start_mcp.py` once — `server.py` / `--stdio` automatically detects the running Relay on `8829` and forwards commands seamlessly!)*

## Step 5 — Activate the In-Game Lucifer Bridge

1. Open **Lucifer v2.88 p2** and go to the **Executor** (`</>`) tab.
2. Paste this 1-line loader and click **Execute**:
   ```lua
   local c = HttpClient.new(); c.url = "http://127.0.0.1:8829/bridge.lua"; local r = c:request(); load(r and r.body or c.content)()
   ```
   *(Or open `scripts/lucifer_bridge.lua` generated by `start_mcp.py` and click **Execute**.)*
3. Check the **[Console]** / **[Logs]** tab — you should see:
   `LUCIFER MULTIBOT BRIDGE STARTED (v2.5)`

Now try asking your AI:
- *"Check `luci_fleet_status` — which bots are online and what worlds are they in?"*
- *"Inspect the current world and count how many Pepper Trees are ready to harvest."*
- *"Warp all bots to `MYFARM` and render a live minimap."*
- *"Check what seeds I need for Door mass and whether my bots have them in inventory."*

## 🔑 Optional — `glServer.exe` Google Login Setup

If you use Google Login in Lucifer and see `"Couldn't Solve Captcha."`:
1. In the `glServer.exe` console, type:
   ```cmd
   set useHeadless False
   set userInteraction True
   set saveProfile True
   ```
2. Type `server` in `glServer.exe`, copy the `localhost:4580:<accessKey>` line, and connect it in Lucifer's **Gmaillog Settings** tab (or pass it to `luci_glserver_set`).
3. Solve the browser verification once — Chrome saves your profile so future logins pass automatically.
